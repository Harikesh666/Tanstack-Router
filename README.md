# TanStack Router Learning Project (React + TypeScript + Vite)

This is my first project using TanStack Router, and the goal of this repo is learning TanStack Router fundamentals in a practical way.

## Current Setup

- React + TypeScript + Vite
- TanStack Router with file-based routing
- TanStack Router Vite plugin (`@tanstack/router-plugin`)
- Generated route tree (`src/routeTree.gen.ts`)
- Router Devtools enabled in the root route

## Project Structure

- `src/main.tsx`: Creates the router with `createRouter({ routeTree })` and renders `RouterProvider`.
- `src/routes/__root.tsx`: Root layout with `<Outlet />`, nav links, and `<TanStackRouterDevtools />`.
- `src/routes/index.tsx`: Home route (`/`).
- `src/routes/about.tsx`: About route (`/about`).

## Run Locally

```bash
pnpm install
pnpm dev
```

## Learning Checklist For This Repo

1. Add one nested route (for example: `/posts` + `/posts/$postId`).
2. Add one pathless layout route using `_` naming.
3. Add and validate one search param (for example: `?page=1`).
4. Add one route `loader` and `loaderDeps`.
5. Confirm route behavior in TanStack Router Devtools.

## Notes

- Do not manually edit `src/routeTree.gen.ts`; it is generated by TanStack Router.
- For Vite + file-based routing, keep `tanstackRouter(...)` before `react()` in `vite.config.ts`.
